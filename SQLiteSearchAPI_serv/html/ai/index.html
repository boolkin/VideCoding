Справка по поиску

Как работает поиск:

  • Введите одно или несколько слов в поле поиска.
  • Нажмите кнопку Поиск или клавишу Enter.
  • Результаты отобразятся в левой панели.
  • Кликните по результату, чтобы увидеть полные данные справа.

Фильтры:

  • Нажмите ☰, чтобы открыть панель фильтров.
  • Выбирайте нужные базы данных и таблицы для сужения поиска.
  • По умолчанию выбраны все таблицы.
  • Переключатель "Отключить лимит" снимает ограничение на количество выдаваемых записей (по умолчанию сервер ограничивает выдачу).

Подсветка:

В деталях записи найденные слова будут подсвечены желтым цветом.
