Справка по поиску

Как работает поиск:

  • Введите одно или несколько слов в поле поиска. Рекомендуется вводить слова без окончаний, чтобы захватить больше результатов (например: "булк 2025 ошиб" - журналы Булкина за 2025 год содеражащие слово ошибка, ошибок, ошибки)
  • Нажмите кнопку Поиск или клавишу Enter.
  • Результаты отобразятся в левой панели в виде списка документов, содеражащие все эти слова.
  • Кликните по результату, чтобы увидеть полный документ справа.

Фильтры:

  • Нажмите ☰, чтобы открыть панель фильтров.
  • Выбирайте нужные базы данных и таблицы для сужения поиска (по умолчанию выбраны все таблицы).
  • В скобках можно указывать синонимы, например "(loft лофт) 41"
  • Переключатель "Отключить лимит" снимает ограничение на количество выдаваемых записей (по умолчанию сервер ограничивает выдачу).

Подсветка:

В деталях записи найденные слова будут подсвечены желтым цветом.
